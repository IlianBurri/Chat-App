1. Installieren

Am schnellsten geht es mit einem Befehl. Er lädt die passende Version, prüft die Prüfsumme und installiert Hallo:

SystemBefehl
Windows (PowerShell)irm https://ilianburri.github.io/Chat-App/install.ps1 | iex
macOS und Linux (Terminal)curl -fsSL https://ilianburri.github.io/Chat-App/install.sh | sh

Lieber mit der Maus? Dann lade den Installer auf der Download-Seite herunter.

Windows

  1. Hallo-Setup.exe öffnen.
  2. Zeigt Windows «Der Computer wurde durch Windows geschützt», auf Weitere Informationen und dann Trotzdem ausführen klicken. Die Meldung kommt, weil der Installer noch nicht mit einem kostenpflichtigen Zertifikat signiert ist.
  3. Sprache wählen, Installationsordner bestätigen und auf Installieren klicken. Administratorrechte braucht es nicht.

macOS

  1. Das Disk-Image für deinen Mac öffnen: «Apple-Chip» für Macs ab 2020 mit M1 und neuer, sonst «Intel». Im Apple-Menü unter «Über diesen Mac» steht, welcher Chip verbaut ist.
  2. Hallo in den Ordner Programme ziehen.
  3. Meldet macOS beim ersten Öffnen, dass Hallo nicht überprüft werden kann: in den Systemeinstellungen → Datenschutz & Sicherheit nach unten scrollen und Dennoch öffnen wählen. Mit dem Installationsbefehl im Terminal entfällt dieser Schritt.
  4. Für Anrufe fragt macOS einmal nach Kamera und Mikrofon. Zum Teilen des Bildschirms Hallo unter Datenschutz & Sicherheit bei der Bildschirmaufnahme erlauben (je nach macOS-Version «Bildschirmaufnahme» oder «Bildschirm- und Systemaudioaufnahme»).

Linux

  • Debian, Ubuntu, Linux Mint: sudo apt install ./hallo-linux-amd64.deb im Download-Ordner.
  • Andere Distributionen: das AppImage ausführbar machen (chmod +x Hallo-linux-x86_64.AppImage) und starten. AppImages brauchen FUSE 2, je nach Distribution das Paket libfuse2 oder fuse2.

2. Erster Start: eigener Server oder verbinden

Beim ersten Start fragt ein Assistent, wie du Hallo nutzen möchtest. Später änderst du das jederzeit unter Datei → Einstellungen (Ctrl+,, auf dem Mac ⌘+,).

Eigenen Server starten

Dieser Computer wird der Server für dein Team. Hallo startet ihn im Hintergrund, sobald die App läuft. Wähle einen Computer, der während der Arbeitszeit eingeschaltet ist.

  • Port: Standard ist 4000. Nur ändern, wenn ein anderes Programm diesen Port schon nutzt.
  • Im lokalen Netzwerk erreichbar: Ein, damit andere sich verbinden können. Der Assistent zeigt die Adressen dafür an. Aus, wenn du Hallo nur allein ausprobieren möchtest.
  • Mit Demo-Daten starten: sechs Beispiel-Konten mit Chats und Terminen zum Ausprobieren, Passwort Demo1234!. Für den echten Einsatz besser leer starten.

Danach registrierst du dich als erste Person mit Name, E-Mail und Passwort.

Windows fragt beim ersten Start mit «Im lokalen Netzwerk erreichbar», ob Hallo im Netzwerk kommunizieren darf. Erlaube den Zugriff für private Netzwerke, sonst erreichen die anderen den Server nicht.

Mit einem Server verbinden

Gib die Adresse ein, die dir die Person mit dem Server nennt, etwa 192.168.1.20:4000. Hallo prüft die Verbindung, bevor es weitergeht. Danach meldest du dich an oder legst ein Konto an.

3. Team einladen

  1. Auf dem Server-Computer im Menü Datei → Server-Adresse kopieren wählen (oder über das Hallo-Symbol im Infobereich).
  2. Die Adresse an dein Team schicken, zusammen mit dem Link zur Download-Seite.
  3. Alle installieren Hallo, wählen Mit einem Server verbinden und legen ihr Konto an.
  4. Arbeitsgruppen erstellst du unter Gruppen; dort lädst du Mitglieder und Gäste ein.

4. Im Alltag

  • Infobereich: Schliesst du das Fenster, läuft Hallo im Infobereich (Windows, Linux) bzw. im Dock (macOS) weiter. So kommen Benachrichtigungen an, und der Server bleibt für dein Team erreichbar. Beenden über das Symbol oder Datei → Beenden.
  • Ungelesenes: Ein Punkt am Symbol und eine Zahl im Dock zeigen neue Nachrichten.
  • Beim Anmelden starten: in den Einstellungen oder im Menü des Symbols ein- und ausschalten. Hallo startet dann direkt im Hintergrund.
  • Bildschirm teilen: Im Anruf auf «Teilen» klicken und einen Bildschirm oder ein Fenster wählen.
  • Suche: Ctrl+K durchsucht Personen, Nachrichten, Dateien und Gruppen.

5. Daten und Sicherung

Auf dem Server-Computer liegen Datenbank, hochgeladene Dateien, Einstellungen und das Server-Protokoll in einem Ordner (Menü Datei → Datenordner öffnen):

SystemDatenordner
Windows%APPDATA%\Hallo
macOS~/Library/Application Support/Hallo
Linux~/.config/Hallo

Sichern: Hallo beenden und die Datei hallo.db sowie den Ordner uploads kopieren, am besten regelmässig auf ein anderes Laufwerk. Wiederherstellen: Hallo beenden, beides zurückkopieren, Hallo starten.

Auf den Computern, die sich nur verbinden, liegen keine Chats und Dateien, nur die Einstellungen.

6. Aktualisieren und deinstallieren

Aktualisieren: die neue Version herunterladen und installieren, oder den Installationsbefehl erneut ausführen. Daten und Einstellungen bleiben erhalten. Aktualisiere zuerst den Server, dann die übrigen Computer.

Deinstallieren: Unter Windows über Einstellungen → Apps, unter macOS Hallo aus «Programme» in den Papierkorb ziehen, unter Linux sudo apt remove hallo bzw. das AppImage löschen. Der Datenordner bleibt dabei bewusst erhalten; lösche ihn von Hand, wenn du auch die Daten entfernen möchtest.

7. Hallo im Browser und über das Internet

Jeder Hallo-Server liefert die App auch an Browser aus: Die Server-Adresse im Browser öffnen genügt, etwa auf dem Handy im selben WLAN. Browser erlauben Kamera, Mikrofon und Bildschirmfreigabe aber nur über HTTPS. Im lokalen Netzwerk ohne HTTPS funktionieren Anrufe deshalb nur in der Desktop-App.

Soll Hallo auch von unterwegs erreichbar sein, gehört der Server hinter einen Reverse Proxy mit HTTPS-Zertifikat (z. B. Caddy oder nginx) auf einem Server mit fester Adresse. Für Anrufe über verschiedene Netzwerke hinweg braucht es zusätzlich einen STUN- bzw. TURN-Server. Die nötigen Einstellungen beschreibt die Server-Dokumentation.

8. Wenn etwas nicht klappt

«Port 4000 ist schon belegt»

Läuft Hallo schon (auch im Infobereich)? Sonst nutzt ein anderes Programm den Port. Wähle unter Einstellungen einen anderen Port, etwa 4100, und gib deinem Team die neue Adresse.

«Server ist nicht erreichbar»

Läuft Hallo auf dem Server-Computer, und ist dort «Im lokalen Netzwerk erreichbar» eingeschaltet? Sind beide Computer im selben Netzwerk (nicht im Gäste-WLAN)? Hat die Firewall des Server-Computers Hallo für private Netzwerke erlaubt? Danach in Hallo auf Erneut versuchen klicken.

Kamera oder Mikrofon funktionieren nicht

Unter macOS in Systemeinstellungen → Datenschutz & Sicherheit → Kamera bzw. Mikrofon Hallo erlauben. Unter Windows unter Einstellungen → Datenschutz und Sicherheit → Kamera den Zugriff für Desktop-Apps einschalten. Nutzt ein anderes Programm die Kamera gerade, gib sie dort frei.

Bildschirmfreigabe zeigt nichts an (macOS)

Hallo unter Systemeinstellungen → Datenschutz & Sicherheit bei der Bildschirmaufnahme erlauben und Hallo neu starten.

Das AppImage startet nicht (Linux)

Meist fehlt FUSE 2: sudo apt install libfuse2 (Ubuntu, Debian) bzw. sudo dnf install fuse (Fedora). Auf Debian und Ubuntu ist das .deb-Paket die einfachere Wahl.

Wo finde ich Fehlermeldungen des Servers?

Im Menü Datei → Server-Protokoll öffnen, oder als logs/server.log im Datenordner. Schick die letzten Zeilen mit, wenn du Hilfe suchst.
