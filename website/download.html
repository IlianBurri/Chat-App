Hallo herunterladen

Kostenlos für Windows, macOS und Linux. Wähle dein System, oder installiere Hallo mit einem einzigen Befehl.

Windows Dein System

Windows 10 und 11, 64 Bit. Setup-Assistent auf Deutsch, ohne Administratorrechte.

Hallo-Setup.exe

PowerShell:

irm https://ilianburri.github.io/Chat-App/install.ps1 | iex

macOS Dein System

macOS 12 oder neuer. Disk-Image öffnen und Hallo in den Ordner «Programme» ziehen.

Mac mit Apple-Chip Mac mit Intel-Prozessor

Terminal:

curl -fsSL https://ilianburri.github.io/Chat-App/install.sh | sh

Linux Dein System

64 Bit (x86_64). AppImage für alle Distributionen, Paket für Debian und Ubuntu.

AppImage .deb für Debian und Ubuntu

Terminal:

curl -fsSL https://ilianburri.github.io/Chat-App/install.sh | sh

Was die Installationsbefehle tun

Sie laden die neueste Version für dein System von GitHub herunter, prüfen die SHA-256-Prüfsumme und installieren erst, wenn sie stimmt. Unter Windows landet Hallo für deinen Benutzer in %LOCALAPPDATA%\Programs\Hallo, unter macOS im Ordner «Programme», unter Linux als Paket oder als AppImage in ~/.local/bin. Die Skripte kannst du vorher ansehen: install.ps1, install.sh.

Prüfsummen

Zu jeder Version gibt es eine Datei SHA256SUMS.txt. Vergleiche sie nach einem Download im Browser mit Get-FileHash Hallo-Setup.exe (Windows) oder shasum -a 256 <Datei> (macOS, Linux). Ältere Versionen findest du unter Releases.

Systemanforderungen

64-Bit-System, 4 GB Arbeitsspeicher, 300 MB freier Speicher. Für Anrufe Kamera und Mikrofon. Als Server reicht ein normaler Bürocomputer, der während der Arbeitszeit läuft.

Ohne Installation, im Browser

Läuft im Team bereits ein Hallo-Server, öffnest du Hallo auch im Browser über seine Adresse, etwa auf dem Handy. Für Anrufe im Browser braucht der Server HTTPS; die Desktop-App kommt im lokalen Netzwerk auch ohne aus. Mehr dazu in der Anleitung.
